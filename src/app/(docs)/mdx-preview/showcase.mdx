## Code

Inline `pnpm dev` should look different from a fenced code block. Fenced code is syntax highlighted with Shiki (`github-light` / `github-dark` themes) and rendered inside the shared `CodeBlock` shell with a copy button and scroll viewport.

```tsx
export function Greeting({ name }: { name: string }) {
  return <strong>Hello, {name}!</strong>
}
```

```bash
pnpm dev
pnpm build
```

## Steps

<Steps>
  <Step title="Install MDX">

Run the `pnpm` commands from your project root.

  </Step>
  <Step title="Edit your theme">

Adjust the inline Tailwind classes in `mdx-components-map.tsx`. The layout should still work on a narrow screen.

  </Step>
  <Step title="Add your content">

Write another `.mdx` file and render it in a page; the shared component map styles it automatically.

  </Step>
</Steps>
