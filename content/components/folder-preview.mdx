## Overview

`FolderPreview` is a folder tile with a cover. At rest it reads as a single
folder; on hover the cover image lifts out of the frame and the folder scales up
slightly, so the component can advertise what is inside without a second screen
or a modal.

Every part is configurable: the two gradients, the frame, the highlight bands,
the label colour, the image panel's geometry, and the spring itself.

## Behaviour

- **Hover** lifts the image panel and scales the folder by `animation.hoverScale`.
- **`animation.enabled: false`** renders the folder still; the image panel stays
  in its initial position.
- **`showLabel: false`** drops the caption but keeps the layout otherwise
  unchanged.
- Gradient ids come from `useId`, so several folders on one page cannot share
  (or overwrite) each other's gradients.
- The image is a plain `<img>`, so the component works with any asset pipeline.
